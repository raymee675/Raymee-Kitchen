# 温度設定・固定90秒・横画面ヘルプ対応 実装計画

作成日：2026年10月3日  
状態：実装済み（型確認・ビルド・画面実機確認は未実施）

## 目的と期待する挙動

- タイマーは常に90秒で計算し、開始後も設定時間を変更できない。
- 楕円ごとに、従来「設定時間」を表示していた位置へ温度を表示する。新規追加時は96℃、既存の左右矢印で待機中・計測中の温度を1℃ずつ変更する。
- 横画面の短い表示領域でも「使い方」ダイアログの全文と閉じる操作へアクセスできる。必要な場合はダイアログ内をスクロールできる。
- PC版とPages版で同じ操作・表示を保ち、保存済み盤面を読み込み時に失わない。

## 現行実装と制約

- 現行の調理画面は `app/kitchen.tsx`、タイマー計算と操作検証は `lib/kitchen-model.ts` にあり、両版が共用する。時間の初期値は100秒、許容範囲90〜110秒。
- PC版は `server/storage.mjs` がSQLite内の盤面JSONを読み書きする。Pages版は `lib/local-kitchen-storage.ts` が `schemaVersion: 1` のlocalStorageを検証する。既存要素には温度項目がないため、どちらにも後方互換が必要。
- 左右矢印はポインター操作・キーボード・`operate_kitchen` WebMCP操作から同じ `adjust` command を送る。画面ラベル、ヘルプ、フッター、READMEにも時間調整の説明がある。
- 横画面ヘルプは `DialogContent` の中央固定表示だが、現状は最大高・内部スクロール指定がない。共通Dialog全体への影響を避け、使い方ダイアログに限定したスタイルにする。
- 既存の設計計画はアーカイブ済み。過去の仕様を書き換えず、この計画と現行READMEを使う。

## 影響範囲

- `cooking-app/lib/kitchen-model.ts`：90秒固定の定数・残り時間計算、温度フィールド、1℃調整command。
- `cooking-app/server/storage.mjs` と `cooking-app/lib/local-kitchen-storage.ts`：旧JSON/localStorage要素に温度96℃を補う読み込み移行。PC盤面・Pages保存のID、位置、開始時刻、revision/versionは維持する。
- `cooking-app/app/kitchen.tsx`：温度表示、矢印とキーボードの温度調整、ariaラベル・トースト・ヘルプ・フッター・WebMCP説明。
- `cooking-app/app/globals.css`：使い方ダイアログだけに最大高と縦スクロールを設定し、横画面で確認。
- `cooking-app/README.md`：現行操作説明を90秒固定・温度設定に更新。
- `cooking-app/tests/model.test.mjs` と `cooking-app/tests/pc.integration.mjs`：既存の旧タイマー仕様の期待値・保存データfixtureを新仕様へ更新する（テストは追加・実行しない）。

## 手順と担当

1. **Luna実装担当**：モデル上の可変時間調整を除き、90秒固定と温度調整commandへ切り替える。新規要素の温度を96℃にする。
2. **同担当**：PC盤面JSONとPages localStorageの旧形式を温度96℃として読み込めるようにし、既存データを捨てずに新形式へ保存できるようにする。旧 `duration` はタイマー動作に使わない。
3. **同担当**：共有画面、WebMCP、操作案内、READMEを新仕様に合わせる。使い方Dialogへ局所的な最大高・スクロールを加える。
4. **Sol**：計画と差分を確認し、互換性・受け入れ条件を独立レビューする。
5. **Luna実装担当**：既存モデルテストの古い100秒・時間範囲の期待値と盤面fixtureだけを更新し、テストコードを現行仕様に整合させる。新しいテストは追加しない。

## 受け入れ条件と検証

- 新規楕円は96℃を表示し、矢印・左右キーで待機中と計測中に±1℃変わる。変更後の温度は再読込および共有端末の同期後にも保たれる。
- 新規および既存楕円の残り時間・進捗・終了判定は90秒基準で、時間変更commandは受け付けない。温度変更では開始時刻を動かさない。
- PCの既存SQLite盤面とPagesのschemaVersion 1盤面を開いても、要素・位置・状態が保たれ、温度が96℃として扱われる。
- 844×390および667×375相当の横画面で、ヘルプ全文をスクロールで読め、閉じる操作が可能。
- 差分レビューと、可能な範囲で型確認・PC版ビルドを行い、共用モデルの変更が両版のビルドを壊さないことを確認する。既存テストコードは新仕様に整合させるが、テストの追加・実行は依頼範囲に含めない。

## リスク・未確定事項

- 温度の上下限は指定されていない。暫定解釈として既存の90〜110秒制限は流用せず、整数の±1℃調整に別の製品範囲を追加しない。必要な上下限がある場合は別途決定する。
- 既存の進行中タイマーは旧設定が90〜110秒の場合がある。固定90秒へ切り替えると、`startedAt`を維持したまま90秒経過時点で終了し、従来設定より早く終了する要素があり得る。今回の固定化仕様を優先する前提で、移行時にこの挙動を明示して確認する。
