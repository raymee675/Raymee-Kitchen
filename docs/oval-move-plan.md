# 楕円の長押し移動・盤外削除 計画

作成日：2026年10月3日　｜　状態：計画済み・実装未着手

## 目的・期待動作

楕円本体を長押しするとドラッグでき、待機中・計測中・焼き上がりのどの状態でも、鉄板1と2の間を含めて移動可能にする。いずれかの鉄板上で離すと位置を保存する。鉄板外（2枚の間の隙間を含む）で離した場合は、状態を問わずその楕円を削除する。短いタップによる開始・焼き上がりの取り出し、左右矢印による温度変更、キーボード操作は維持する。

## 現行フロー・制約

- `app/kitchen.tsx` の共通 `KitchenView` がPC版とPages版のSVG鉄板を描画する。Pointer Eventsで押下対象を記録し、移動量12 CSS px未満なら離した時点でタップ操作、12 px以上の移動は現在無視する。鉄板SVG上ではPointer Captureを使う。
- `lib/kitchen-model.ts` のCommand・検証・適用処理を両版で共有する。PC版は `lib/use-kitchen.ts` → `/api/board` → `server/storage.mjs` で操作ID・revision・versionを管理し、Pages版は `lib/use-kitchen-local.ts` が同じ `applyCommand` で保存する。
- 楕円には `plate/x/y` とversionがあり、保存形式変更は不要。既存 `clampPosition` と `overlaps` が内側余白・重なりを定める。既存の `remove` は焼き上がりのみ許可するため、ドラッグ盤外削除には専用commandが必要。
- 既存の温度・タイマー変更は未コミット差分を含むため保持し、本計画の範囲だけを変更する。

## 影響範囲・担当

- **GPT-6 Luna実装worker**：`cooking-app/app/kitchen.tsx` に長押し（初期値450 ms）・全状態のドラッグプレビュー・リリース先鉄板判定を実装。矢印上の長押しは移動対象外。短押しと長押し成立前の移動を誤操作にしない。
- **同worker**：`cooking-app/lib/kitchen-model.ts` に `plate/x/y` を更新する移動commandと、version検証付きの任意状態削除commandを追加。移動は `startedAt`・温度・時間を保持し、versionを進める。既存 `clampPosition` で端からのはみ出しを収める。
- **同worker**：ドラッグ中、候補位置が移動先鉄板の他の楕円と重なる場合は無効状態を表示し、離しても保存しない。ヘルプと `cooking-app/README.md` の操作説明を必要箇所のみ更新。CSS変更は視覚フィードバックに必要な場合だけ行う。
- **Sol coordinator**：差分と受け入れ条件を確認する。独立レビューが必要な場合は実装workerとは別のGPT-6 Luna reviewerへ依頼する。

## 検証・受け入れ条件

- 短押し、矢印、キーボードの既存操作が維持され、矢印長押しで楕円が動かない。
- 待機・計測中・焼き上がりの楕円が長押しで鉄板1/2のどちらにも移動でき、`startedAt`・温度・タイマー表示を保つ。移動先は再読込・同期後も保持される。
- ドラッグ中に重なりを検出して無効表示にし、重なった位置で離した場合は位置を確定せず元位置を維持する。鉄板端では既存余白へクランプする。
- 離したポインター座標が両鉄板の表示領域外（隙間を含む）なら、どの状態でも対象だけを削除する。焼き上がりタップ用の既存 `remove` 制約は残す。pointercancel / lost capture は変更を確定しない。
- 最終差分レビュー、`git diff --check`、可能な場合の型確認・両版ビルドを行う。ユーザーから依頼がないためテストは追加・実行しない。実ブラウザー確認が可能ならタッチ・マウス、境界、盤外リリース、キャンセルを確認する。

## リスク・未確定事項

長押し時間450 msは暫定値。盤外は「鉄板境界を越えた瞬間」ではなく「両鉄板の外で離した時」に削除確定と解釈する。ポインターキャプチャ中も座標は各鉄板の画面上の矩形から判定し、縦横レイアウトと隙間で誤削除がないことを確認する。別端末変更とのversion競合時は古い状態を上書きせず、最新状態へ同期して失敗を示す。
