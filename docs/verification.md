# アーカイブ：Site版の実装・検証記録

**2026-10-10更新：以下は2026年9月27日時点のSite版に関する過去の検証記録です。GitHub Pages版や現在のPC legacy実装の検証結果ではありません。現在の運用・サポート対象とPagesの確認状況は[GitHub Pages構成の正本](single-phone-github-pages-architecture.md)を参照してください。記録された検証結果は当時のSite版に限り保持しています。**

検証日：2026年9月27日  
ソース：`cooking-app/`  
構成：React / TypeScript / Vinext / Cloudflare D1 / Sites

## 実装した機能

- 鉄板2枚の表示（スマホ縦向きは上下、横向きは左右）。
- タップ位置への空白楕円の配置。端の補正と重なり防止。
- 空白のタップで100秒の計測を開始。
- 左スワイプで1秒短縮、右スワイプで1秒延長。90〜110秒。
- 開始時刻を維持し、経過に応じて上から白く塗り分け。
- 終了時に赤くし、上スワイプで削除。
- データベースによる永続化、約1秒間隔の共有状態取得。
- サーバー時刻への補正。データベースの処理待ち時間を往復通信時間から除外。
- 同時変更の検出、操作再送の二重適用防止、古い応答による表示巻き戻り防止。
- 接続状態表示、通信停止時の変更抑止、再接続と画面復帰時の再取得。
- 認証済みAPI、所有者限定のSitesアクセス設定。
- PWAのmanifest・アイコン・オフライン案内。
